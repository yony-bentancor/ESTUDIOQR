# Plan de contenidos · Instagram @estudio.qr

Publicación: **martes y sábados**, programada para las **19:00 (hora de Montevideo)**.
Se alterna: un post de **proyecto** (sitios desarrollados) y uno para **atraer clientes** (consejo u oferta).

Cada vez se toma el **primer tema pendiente** (`[ ]`), se publica y se marca `[x]` con la fecha.
Cuando no quedan pendientes, se crean temas nuevos siguiendo la misma mezcla, sin repetir ángulos.

## Reglas

- Tono: cercano, rioplatense (vos), profesional. Sin exagerar.
- **No inventar datos**: nada de porcentajes, cifras, clientes o testimonios que no estén confirmados. Las funciones de un proyecto se describen solo si están en este plan o se comprobaron en el sitio.
- Texto: gancho en la primera línea, 3–6 líneas de valor, llamado a la acción (WhatsApp o DM), `🌐 estudioqr.com.uy` y 6–10 hashtags (#desarrolloweb #montevideo #uruguay #emprendedoresuruguay …).
- Imagen: `instagram/generar.py` (plantillas `proyecto`, `consejo`, `oferta`). Si existe `instagram/capturas/<slug>.png`, se usa en el post del proyecto.
